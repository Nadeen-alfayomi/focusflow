# FocusFlow ✨

A clean, responsive, and local-first habit tracking application designed to help users build consistency through seamless daily progress management.

🚀 **Live Demo:** [Try FocusFlow Live](https://focusflow-nu-blue.vercel.app/)

---

## 🛠️ Tech Stack
* **Frontend:** React.js (Vite)
* **Styling:** React-Bootstrap & Custom CSS
* **Data Persistence:** Browser LocalStorage
* **Deployment:** Vercel

---

## ✨ Key Features
* 📝 **Habit Management:** Easily create, update, and remove daily habits.
* 📌 **Muted Notes:** Add descriptive notes/context to individual habits.
* 💾 **Auto Data Savings:** All habits persist locally using `localStorage` so no data is lost on refresh.
* 📱 **Responsive Design:** Optimized for seamless performance on desktop and mobile viewports.
